# تحضيري — إعلان الملخصات

فيديو عمودي مستقل للتعريف بميزة الملخصات في منصة تحضيري. الرندر النهائي الحقيقي موجود في [`output/tahdiri-summary-ad.mp4`](output/tahdiri-summary-ad.mp4)، والصفحة الرئيسية تعرض الملف نفسه للتشغيل والتنزيل.

## مواصفات التسليم

- MP4 / H.264، ‏1080×1920، ‏30 FPS، صوت AAC.
- المدة: 29.65 ثانية. مصدر التعليق الصوتي هو التسجيل الأصلي المرفق كما هو، بلا قص أو استبدال.
- أُضيفت موسيقى مرخصة بمستوى منخفض مع خفض تلقائي تحت الكلام، ومؤثرات انتقال لطيفة.
- الترجمة العربية مدمجة بصرياً ومتزامنة مع الجمل. الواجهات تستخدم نصوصاً تجريبية عامة ولا تعرض مادة منهجية حقيقية.

## إعادة إنتاج الفيديو في Termux

يتطلب FFmpeg وPython ومهارة FFmpeg التي استُخدمت لإنتاج الملف. شغّل من جذر هذا المستودع:

```sh
export LD_LIBRARY_PATH="$PREFIX/lib"
python "$HOME/work-tools/codex-skills/ffmpeg-skill/scripts/render.py" project/project.json --overwrite
```

ملفات المشاهد الثابتة المصدرية في `scenes/`، ونسخها المتحركة في `assets/rendered-scenes/`. النص والتوقيت في `analysis/captions.ass`، وملف الإعداد في `project/project.json`.

## المعاينة والتنزيل

افتح `index.html` محلياً أو استخدم رابط النشر. زر التنزيل يحفظ ملف MP4 النهائي نفسه.

## الأصول والتراخيص

تفاصيل مصادر لقطات الفيديو والموسيقى ومؤثر الانتقال والخطوط في [`CREDITS.md`](CREDITS.md). التسجيل الصوتي الشخصي محفوظ كملف مصدر داخل المشروع ولا يعاد استخدامه خارج هذا الإعلان.
